# 🚀 NextWork Web Project

A simple Java Maven Web Application built using JSP and deployed on AWS EC2.

## 📌 Project Overview

This project is a basic Java web application created using:

- Java
- Maven
- JSP
- Apache Tomcat
- Git & GitHub
- AWS EC2 (Linux)

The application displays a simple dynamic web page and is structured using Maven standard directory layout.
